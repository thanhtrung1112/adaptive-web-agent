# Tuần 5 — 25–31/10/2026 — KH1-N5

Yêu cầu GVHD ở H45: tạo bộ mutation đổi id/class/text/order/structure và version
benchmark. Nguồn trích chính xác: `Evidence/W05/rubric.json`.

## Sản phẩm

- `app/mutations_w5.py`: năm trục độc lập và tổ hợp, trên HTML thật của MiniBiz.
- `app/mutations.py`, `orders.js`: tích hợp mode W5, giữ context và dòng động.
- `w5/run.py`: replay đủ 30 task với DB/context riêng; ground truth chỉ cho evaluator.
- `w5/probe.py`: 65 probe locator M0, bao gồm phát hiện chọn sai cột.
- `tests/test_w5.py`: kiểm tra biến đổi, seed, CSS, table alignment, ID/label và JS.
- `data/benchmark_v0.5.0.json`: mode/seed/task/data/source hash và quy tắc version.
- `Evidence/W05/`: bảng chỉ số, log, hình, manifest và đối chiếu sáu tiêu chí GVHD.
